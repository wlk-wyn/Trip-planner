# 结果页阅读体验：第一批 UI 调整

日期：2026-10-16。保留白色系与暗色模式，重点改善每日阅读、地图对应和信息层级。

## 已完成

- 桌面以每日行程为主、右侧固定地图，地图默认更大。助手按需展开，并可在桌面收起；打开助手时输入框不再强制滚动页面。
- 日期卡片显示真实的前两个景点、日期和时间状态；标题过长省略但保留完整 title。保留横向滑动、方向键、Home/End 与跨日拖拽。
- 日期切换沿用方向感淡入滑动，420 ms。独立“切换动效”开关默认开启并保存浏览器偏好；关闭时立即切换。这一效果按用户要求可覆盖系统减少动态效果，其他动画仍沿用原有系统规则。
- 全局状态默认显示概况，具体问题折叠；时间预算默认显示结论与细条，分项和依据按需展开。
- 时间线突出地点和开始/结束时间。交通连接默认只显示方式和耗时；线路、票价、距离、换乘、失败说明放在路线详情中，未删除数据。
- 点击时间线地点定位地图，当前地点高亮；地图提供“全日路线”恢复视野。按日切换时同步标题、标记和路线。
- 修复旧版本 schedule ID 与稳定地点 ID 不一致导致地图漏标的问题，兼容 attraction-index、meal-index、餐次和酒店锚点。地图定位失败时给出具体提示。
- 手机增加“当天地图”入口，地图以可收起面板打开；等待布局完成后重算视野，避免使用隐藏容器旧尺寸。助手保留原有底部面板。
- 助手快捷提问的日期跟随当前查看的日期，不再固定“第二天”。

- 原北京 v3 的第 1、2 天切换后，地图各显示酒店和五个游览/餐饮标记；点击中国美术馆后显示选中状态并定位。
- 方向键切换、时间分配展开、桌面助手展开已检查。浏览器实际观察到 `day-switch-enter-active` 和 `transition-duration: 0.42s`。
