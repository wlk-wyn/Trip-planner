首页、结果页、详细设置、PDF/图片工具分别加载；Ant Design 按组件公开入口导入，避免首页提前依赖地图或完整表单。组件类型在检查前稳定生成。详细设置加载失败提供重试，草稿保存在父页面；首次展开后保留组件，以支持平滑收起及保留填写值。

`npm run build` 自动执行类型检查、生产打包和体积门槛：首页 270000 gzip 字节、结果页 320000 字节。首页不得含地图、结果页或详细设置模块，两条路由均不得提前包含 html2canvas/jsPDF。只比较入口文件大小会低估实际加载量，本记录不采用该口径。

## 交互与网络

使用生产构建及独立公开样例数据库，检查详细设置必填校验、重试、草稿保留、中文日期选择器、明暗模式与手机宽度；按 390×844 视口测试时，实际内容区域 375px，页面无横向溢出。结果页关闭动效时的路由空白问题已修复；日切换、快速连点和返回首页通过。日卡高度过渡与详细设置展开可关闭，系统减少动态效果偏好在未手动设置时生效。

API 默认走同源 `/api`，开发和预览通过代理连接后端；正式部署仍需配置反向代理，不能把本地预览当作上线。通过预览代理的独立 SSE 合成任务先后收到 running、running、cancelled 事件，分别约 0.03、10.05、20.05 秒；使用跨进程十秒轮询后备，只证明流未被缓冲到结束，不代表真实模型的阶段延迟。没有获得 FCP、p95 或用户负载结论。

## 图片与 PDF

导出使用独立浅色文档，逐日纵向排列，不改变页面所选日期或主题；只复制样式和内容，不运行应用脚本。去掉照片占位及操作按钮，保留地点标题、时间、地址、交通、费用和未核实说明。费用与来源标签内容全部纳入，不依赖当前选中的补充信息标签。

PDF 逐日处理，避免一次为长行程申请巨大画布；按文字边界分页，可容纳的地点卡片尽量保持完整，标题随首张卡片分页。超出画布上限时明确提示改用离线手册。导出结束或异常时移除临时 iframe。PDF 为位图分页，不能搜索或选择正文；包含完整交通及逐项来源的文件仍较长，不能宣称已经完成精简出行版设计。

实际从生产预览的菜单下载公开北京两天样例：PNG 1384×23517、3174877 字节；PDF 14 页、2146696 字节。PDF 全部渲染并检查页概览，以及卡片与跨页位置；暗色模式导出标题可读，导出后主题保留、临时 iframe 为 0。文件摘要在验收记录中；中间产物位于忽略目录 `frontend/var/export-check`，不是用户交付文档。离线 HTML 与 ICS 也经过实际下载检查。
